# 소음 표

수리는 소리를 낸다. 소리는 선체 밖으로 퍼진다. 시끄러운 일은 때를 골라 한다.

## 읽는 법

- 소음은 0~100 눈금이다. 100에서 그친다.
- 등급은 조용 0~5, 보통 6~20, 시끄러움 21 이상이다.
- 지금 소음은 돌고 있는 장비 소음의 합에 진행 중인 손동작 소음의 합을 더한 것이다.
- 손동작 소음은 정해진 시간 동안 이어진다. 겹치면 더해진다.
- 선체 밖으로 퍼진 소리는 바로 가시지 않는다. 크게 낸 소리일수록 오래 남는다.

## 장비 소음

돌고 있는 동안 계속 난다.

| 장비 | 소음 |
| --- | --- |
| 실내 조명, 계통 상황판, 청음기, 납땜인두 | 0 |
| 사이펀 기록기 | 1 |
| 산소 화로 점화기 | 2 |
| 자이로컴퍼스 | 3 |
| 기계식 항법 계산기 | 4 |
| 송풍 팬 | 5 |
| 탄소 아크 탐조등 | 8 |
| 전동 배수 펌프 | 15 |
| 추진 전동기 | 최대 20. 출력에 비례 |
| 소나 발신 | 30. 1초 |
| 갈고리 윈치 | 30 |

## 손동작 소음

| 동작 | 소음 | 이어지는 시간 |
| --- | --- | --- |
| 칼날 스위치 (위치를 바꿀 때) | 2 | 0.5초 |
| 퓨즈 뽑기, 꽂기 | 2 | 1초 |
| 사물함에서 꺼내기 | 2 | 0.5초 |
| 렌치 (볼트 하나) | 3 | 2초 |
| 덮개 여닫기, 바구니 빼고 넣기 | 4 | 0.8초 |
| 해치 여닫기 | 6 | 1.5초 |
| 솔질 한 번 | 10 | 0.6초 |
| 버팀목 대기 | 10 | 1초 |
| 나무망치 한 번 | 18 | 0.4초 |
| 수동 펌프 한 번 | 25 | 1.2초 |
| 코킹 한 번 | 45 | 3초 |

## 절차별 소음

| 절차 | 가장 큰 소리 | 등급 |
| --- | --- | --- |
| 퓨즈 교체 | 2 | 조용 |
| 펌프 흡입 거름망 청소 | 솔질 10 | 보통 |
| 리벳 이음 응급 막기 (쐐기와 버팀목) | 나무망치 18 | 보통 |
| 리벳 이음 코킹 | 코킹 45 | 시끄러움 |

- 거름망 청소를 마치고 펌프를 돌리면 펌프 소음 15가 이어진다.
- 수동 펌프는 시끄럽다. 오래 저으면 소리가 쌓인다.
- 코킹은 나누어 쳐도 된다. 친 횟수는 이음새에 남는다.

# 용어집

> **요약**: 이야기 글에 나오는 고유명사, 장비, 절차, 통신 용어를 한 곳에 모았다. 장비와 절차 이름은 본선 교범(`data/manual/`)의 말을 그대로 쓴다. ★ 표시는 설계서에 없어서 이 초안에서 새로 정한 이름이다(보고서에 목록이 있다).

## 3. 케이블 작업 용어

| 말 | 뜻 |
| --- | --- |
| 구간 | 노선 위의 거리 표시. "간선 km 412" |
| 단선 | 케이블이 끊김. 이야기에서는 '절연 불량'(심선이 바닷물에 닿음)과 구분한다 |
| 고장 거리 | d(km) = R(Ω) ÷ r(Ω/km). 교범 공식(SPEC 9절) |
| 천해선 ★ | 얕은 곳에 까는 굵은 외장 케이블. r = 2.8Ω/km (가안) |
| 심해선 ★ | 깊은 곳에 까는 가는 외장 케이블. r = 3.4Ω/km (가안) |
| 장하선 ★ | 장하 코일을 감은 심해선. 장하 구간에만 있다. r = 4.1Ω/km (가안) |
| 접속 | 케이블 끝을 챔버로 들여 심선을 잇고 절연하고 피복을 감는 일. 할당량은 접속 건수로 센다 |
| 시험 송신 | 사이펀 기록기로 양쪽 육양국과 시험 신호를 주고받는다. 물결선이 깨끗하면 성공 |
| 물결선 | 사이펀 기록기가 테이프에 그리는 선. 위로 꺾이면 점, 아래로 꺾이면 선 |

## 4. 회사 문서 용어

| 말 | 뜻 |
| --- | --- |
| 지시서 | 임무 첫 전문. 케이블 구간, 할당량, 특이 사항 |
| 결산 | 임무 끝의 회사 전문. 할당 결과와 보급 변화 |
| 할당량 | 근무마다 해내야 하는 접속 건수 |
| 추가 지시 ★ | 임무 중에 오는 위험한 덤 지시. 따르면 결산에서 보급 가점, 안 따라도 할당 미달은 아니다 |
| 보급 카드, 보급 선택 | 출항 전 고르는 편의품. 선택 장수는 결산에서 오르내린다 |
| 근무 표지 ★ | 근무마다 붙는 글자. 1장 첫 근무 A부터 5장 마지막 근무 P까지(I와 O는 쓰지 않는다) |
| 전문 번호 ★ | 근무 안에서 아르고스가 보낸 전문의 차례. 지시서가 01 |
| 검증군 ★ | 전문 머리의 세 글자. 암호표에서 찾아 맞춘다 |
| 암호표 ★ | 교범 바인더 뒤 봉투에 든 표. 판마다 바뀐다. 현재 제4판 |

## 6. 통신 약어 (6장 모스 교신)

| AR | 전문 끝 |
| SK | 교신 끝 |
| 73 | 잘 가라(인사) |

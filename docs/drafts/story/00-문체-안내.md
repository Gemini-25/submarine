# 문체 안내

> **요약**: 게임 속 모든 글은 1930년대 해저 전신 회사의 문서처럼 쓴다. 짧은 문장, 담담한 말투, 감정은 사실 뒤에 숨긴다. 공포는 양념이다. 무서운 일을 무섭다고 쓰지 않는다. 이 문서는 지시서, 결산, 기록물, 교신을 쓰는 사람이 지킬 규칙이다.

## 1. 공통 원칙

1. **짧게 쓴다.** 한 문장에 한 가지 사실. 쉼표가 두 개 넘으면 문장을 나눈다.
2. **사실을 먼저 쓴다.** 수심, 시각, 구간, 계기 값. 느낌은 쓰지 않거나 맨 끝에 한 줄.
3. **무섭다고 쓰지 않는다.** "끔찍한", "섬뜩한", "공포" 같은 낱말은 쓰지 않는다. 이상한 것은 이상한 그대로 적는다. "자국이 있다. 닻 자국이 아니다."
4. **설명할 수 있게 쓴다.** 모든 현상에는 물리적 원인이 있다(설계서 9절). 글은 원인을 숨길 뿐 거짓말하지 않는다. 나중에 답이 나왔을 때 앞의 글이 틀리면 안 된다.
5. **교범과 같은 말을 쓴다.** 장비와 절차 이름은 `01-용어집.md`를 따른다. 교범이 '전중 빌지'라 하면 기록물도 '전중 빌지'다.
6. **게임 밖 조작 키는 쓰지 않는다.** "Tab을 눌러" 대신 "교범을 펴라".
7. **숫자는 아라비아 숫자, 단위는 교범과 같게.** 120V, 분당 120L, 수심 340m.

## 2. 목소리별 규칙

### 회사 (대양전신회사, 아르고스호 통신실)

- 전보체. "~할 것.", "~바람.", "~함." 으로 끝낸다.
- 주어를 거의 쓰지 않는다. 기관사를 부를 때는 "모스호 기관사" 또는 "귀선".
- 위험을 낮춰 말한다. "약간의 해류가 예상됨", "절차대로 하면 문제없음".
- 칭찬은 숫자로 한다. "할당 달성. 다음 보급 선택 4장."
- 사과하지 않는다. 핑계는 '사정'이라 부른다. "회사 사정으로 보급 1장 감함."

### 교범 (정비 교범)

- 이미 본선에 있다. 그대로 따른다. 명령형 평서문. "먼저 이 책을 편다." "순서를 어기면 다친다."
- 이야기 글이 교범을 흉내 낼 때(전임 기관사가 교범 여백에 쓴 메모)는 교범 문장 옆에 손글씨가 붙는 꼴이다.

### 전임 기관사 요나스 소렐 (녹음판, 일지, 메모)

- 녹음판: 말이다. 문장이 더 짧고 끊긴다. 혼잣말과 다음 사람에게 하는 말이 섞인다. 반말. 숨소리, 쉼, 바늘 긁히는 소리를 대본에 [ ] 로 적는다.
- 일지: 업무 기록. 날짜 대신 근무 표지와 수심. 처음엔 반듯하고, 4장 무렵부터 문장이 짧아지고 줄이 비뚤어진다(필체 변화는 [ ] 로 지시).
- 메모: 요령과 경고. 명령형 반말. "펌프 소리가 높아지면 조개다."
- 소렐은 유능하고 건조하다. 겁먹은 사람이 아니라 계산하는 사람이다. 그래서 그가 망설이는 대목이 무섭다.

### 벨호 기관사 마테오 린 (6장 기록물)

- 소렐과 같은 학교 출신. 더 젊고 말이 많다. 농담을 한다. 마지막으로 갈수록 농담이 줄고 절차만 남는다.

### 마레 육양국 (6장 교신)

- 모스 부호. 국제 약어와 짧은 영어 낱말. 화면에는 테이프 원문과 한국어 뜻을 함께 보인다.

## 3. 공포를 쓰는 법

- **빈자리로 쓴다.** 있어야 할 것이 없다. 소리가 멈춘다. 답신이 오지 않는다.
- **계기로 쓴다.** "수압계 바늘이 20m만큼 튀었다가 돌아왔다. 수심은 바뀌지 않았다."
- **반복으로 쓴다.** 같은 문장이 두 번 나오면 두 번째가 무섭다.
- **큰 것은 끝까지 쓰지 않는다.** "소나 가장자리에 무언가 걸렸다. 다음 핑에는 없었다." 이상은 쓰지 않는다.
- **한 글에 한 번만.** 기록물 하나에 이상한 대목은 한 줄이면 충분하다. 나머지는 일 이야기다.

## 4. 형식 규칙

| 종류 | 형식 |
| --- | --- |
| 지시서와 회사 전문 | 머리(발신, 수신, 근무 표지, 전문 번호, 검증군) + 본문 + 끝맺음 `끝.` |
| 결산 | 회사 전문 한 장. 할당 결과, 보급 변화, 한 줄 평 |
| 녹음판 | 제목 딱지(손글씨) + 대본. 1분 안팎 |
| 일지 | 근무 표지, 수심, 본문 3~6줄 |
| 메모 | 1~3줄 |
| 모스 교신 | 테이프 원문 / 부호 / 한국어 뜻 |

### 전문 머리 형식

```
대양전신 아르고스 발 → 모스호 수
근무 표지 A · 전문 01 · 검증군 NSE
```

- 근무 표지, 전문 번호, 검증군의 뜻과 검증 방법은 `거짓-신호.md`에 있다. 1장부터 모든 회사 전문이 이 머리를 단다. 4장까지는 형식일 뿐이고, 5장에서 쓸모가 생긴다.

## 5. 쓰지 않는 것

- 감탄사와 느낌표. 예외: 녹음판의 혼잣말, 6장 교신의 한 번.
- 현대어와 외래어 남용. "체크", "OK", "레벨" 대신 "확인", "좋다", "수위".
- 생물의 생김새를 길게 묘사하는 문장.
- 플레이어의 감정을 정해 주는 문장. "당신은 두렵다" 같은 것.

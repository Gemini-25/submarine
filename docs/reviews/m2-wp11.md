3. **[major/sim]** `data/fixtures/power.json` — battery.cell.{n} insert accepts "cell_dead": {} (76행). pull에 health를 비우는 set이 없음

   - 고칠 것: pull 동사에 `"set": { "health": 0 }`을 더해 빈 자리에 health가 남지 않게 한다. Execute에서 gives가 v.Set보다 먼저 평가되므로, 주는 물건은 원래 health로 정해진다. accepts는 `"cell_dead": { "set": { "health": 0.3 } }`(PWR-01의 값)으로 하고, 0번 항목의 `"cell_used": { "set": { "health": 1 } }`과 함께 health가 자리가 아니라 꽂는 셀을 따라가게 한다. 0번 항목대로 성한 셀이 scrap인 `cell_used`로 나오면 `locker.return.spare_cell`로 재고를 늘리는 길도 막힌다. 시험을 더한다. PWR-01 cell.3에서 cell.1을 빼고 cell.3의 다 쓴 셀을 cell.1 자리에 꽂으면 cell.1 전압이 약 13V로 남고 charge가 0.9로 바뀌지 않아야 한다. 또 예비 셀 재고 0에서는 cell.3 자리를 성하게 채울 수 없어야 한다. charge는 자리에 남는다(셀을 따라가지 않는다). 이 단순화는 보고서 결정 절에 적는다.

# 눈 가리고 듣기 정답 (먼저 들은 뒤에 열 것)

`dotnet run --project tools/DeepLine.AudioRender -- blind --seed 1027`로 만든 세트. 파일은 `docs/reports/audio/blind/`.
네 파일 모두 펌프가 이미 돌고 있는 상태에서 8초. 음량은 손대지 않았다.

| 파일 | 정답 |
| --- | --- |
| A.wav | 흡입구 막힘 (WTR-01) |
| B.wav | 정상 (normal) |
| C.wav | 역류 방지 밸브 고착 (WTR-03) |
| D.wav | 베어링 마모 (WTR-02) |

# 윈치 브레이크

분류: 케이블 · 윈치 브레이크 마모 (CBL-01)

갈고리 윈치는 후방 구역 우현, 해치 쪽에 있다. 드럼을 감싼 띠 브레이크가 하중을 잡는다. 띠 안쪽에 라이닝이 붙는다. 띠는 턴버클로 조인다.

## 이럴 때 쓴다

- 상황판 케이블 표시등이 빨강이고 벨이 울렸다.
- 조종 레버가 멈춤에 있는데 드럼이 조금씩 풀려 나간다.
- 줄 계수기가 저절로 오른다.
- 와이어가 풀리며 쉭 하는 소리와 브레이크 끽 소리가 난다. 미끄러질수록 소리가 높아진다.
- 점검창 너머 라이닝이 얇다.

## 어디에

- 윈치 구동부: 후방 우현, 해치 격벽 앞. 복도 쪽 면에 조종 레버, 멈춤쇠, 띠 덮개가 있다.
- 줄 계수기와 하중계: 구동부 위 앞면.
- 새 라이닝: 후방 예비품 사물함.
- 윈치 전동기는 케이블 장비 회로(C6)에서 전기를 받는다.

## 무엇이 있나

| 이름 | 하는 일 |
| --- | --- |
| 조종 레버 | 감기, 멈춤, 풀기 세 자리. 한 칸씩 움직인다 |
| 멈춤쇠 | 드럼이 풀리는 쪽으로 돌지 못하게 건다. 감는 쪽으로는 걸리지 않는다 |
| 띠 덮개 | 볼트 두 개가 누른다. 안에 라이닝이 있다 |
| 브레이크 라이닝 | 띠 안쪽의 마찰재. 닳으면 얇아진다 |
| 브레이크 턴버클 | 띠를 조인다. 렌치로 한 번에 한 눈금 |
| 점검창 | 라이닝 두께가 보인다 |
| 미끄럼 스위치 | 드럼이 멈춤에서 풀려 나가면 닫힌다. 상황판 케이블 표시등에 물려 있다 |

## 브레이크가 잡는 힘

- 새 라이닝에 턴버클이 맞으면 약 {{n:tuning.cable.winch.brakeMaxKg}}kg을 잡는다.
- 라이닝이 닳은 만큼 잡는 힘이 준다. 라이닝이 3할 남으면 약 120kg만 잡는다. 시험 하중 180kg은 미끄러진다.
- 미끄러지면 라이닝이 더 닳는다. 미끄러짐은 점점 빨라진다.
- 줄은 {{n:tuning.cable.winch.lineMaxM}}m까지 감겨 있다. 다 풀리면 줄 끝이 드럼에서 빠지고 하중을 잃는다.
- 멈춤쇠를 걸면 미끄러짐이 그친다. 수리가 아니다. 하중을 잡아 둘 뿐이다.

## 끝난 뒤 확인

- 멈춤에서 줄 계수기가 서 있다.
- 상황판 케이블 표시등이 꺼져 있다.
- 감을 때 띠 덮개가 뜨거워지지 않는다.

## 순서를 어기면

- **멈춤쇠를 먼저 건다.** 멈춤쇠 없이 하중이 걸린 채로 라이닝을 빼면 드럼이 헛돈다. 손이 끼이고 줄이 다 풀려 하중을 잃는다.
- 드럼이 빨리 돌 때에는 멈춤쇠가 튕겨 나와 걸리지 않는다. 미끄러짐이 느릴 때 건다.
- 감기 중에 띠 안에 손을 넣으면 끼인다. 조종 레버를 멈춤에 두고 전동기를 끈다.
- 턴버클을 끝까지 조인 채로 두면 감을 때 띠가 드럼에 끌린다. 감기가 느려지고 띠가 달아오른다. 라이닝이 네 배로 빨리 닳는다.
- 턴버클을 너무 많이 되돌리면 시험 하중은 잡아도 무거운 하중은 미끄러진다. 끝까지 조인 자리에서 두 번에서 네 번 되돌린 자리가 맞다.
- 닳은 라이닝을 도로 끼우면 고쳐지지 않는다.

## 응급 수리

없다. 라이닝이 떨어졌으면 멈춤쇠를 걸어 하중을 잡아 둔다.

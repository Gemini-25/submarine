# 사이펀 기록기

분류: 케이블 · 사이펀 막힘 (CBL-02)

사이펀 기록기는 전방 구역 우현, 통신 책상 위에 있다. 가는 유리 모세관이 잉크 우물의 잉크를 펜 끝까지 끌어올린다. 신호가 오면 펜이 좌우로 흔들려 흐르는 테이프에 물결을 그린다. 상황판에는 표시등이 없다. 테이프를 보고 판단한다.

## 이럴 때 쓴다

- 시험 키를 눌렀는데 물결이 끊어져 점선이 된다.
- 시험 키를 눌렀는데 테이프에 아무것도 그려지지 않는다.
- 펜 끝에 마른 잉크 딱지가 앉았다.
- 잉크병 눈금이 바닥 가까이 내려가 있다.
- 펜이 테이프를 긁는 소리가 나지 않는다.

## 어디에

- 기록기: 전방 우현 통신 책상. 펜 팔, 모세관, 잉크 우물, 마중 고무공, 시험 키, 테이프 창, 증폭관이 한데 있다.
- 잉크병: 예비품 사물함.
- 기록기는 케이블 장비 회로(C6)에서 전기를 받는다.

## 무엇이 있나

| 이름 | 하는 일 |
| --- | --- |
| 펜 팔 | 내리면 펜이 테이프에 닿는다. 들면 떨어진다 |
| 모세관 | 잉크를 펜 끝으로 끌어올린다. 마른 잉크가 막는다 |
| 잉크 우물 | 잉크를 담는다. 잉크병으로 채운다 |
| 마중 고무공 | 눌러서 모세관에 잉크를 채운다 |
| 시험 키 | 누르면 {{n:tuning.cable.siphon.testSeconds}}초 동안 시험 신호가 간다 |
| 증폭관 | 신호를 키워 펜을 흔든다 |

## 테이프 읽는 법

<!-- pair:siphon.trace -->

| 테이프 | 뜻 | 확인 |
| --- | --- | --- |
| 끊김 없는 물결 | 정상 | — |
| 점선 물결 | 모세관이 반쯤 막혔다 | 펜 끝의 딱지 |
| 펜은 흔들리는데 아무것도 그려지지 않는다 | 잉크 길이 끊겼다: 막힘, 잉크 바닥, 마중물 빠짐, 펜 팔이 들림 | 딱지, 잉크병 눈금, 펜 팔 |
| 곧은 줄만 그려진다 | 신호가 오지 않는다. 잉크 길은 성하다 | 증폭관이 빠졌거나 꺼졌다 |
| 테이프가 멈춰 있다 | 기록기에 전기가 없다 | C6 퓨즈와 스위치 |

- 펜은 신호를 그리는 동안만 잉크를 쓴다. 잉크가 바닥나면 모세관에 공기가 든다. 다시 마중물을 채워야 한다.

{{procedure:proc.siphon.clear}}

## 끝난 뒤 확인

- 시험 키를 누르면 끊김 없는 물결이 그려진다.
- 펜이 테이프를 긁는 소리가 난다.
- 잉크병 눈금이 위에 있다.

## 순서를 어기면

- 펜 팔을 내린 채로는 바늘이 모세관에 들어가지 않는다.
- 쑤시고 나면 모세관에 공기가 든다. 마중물을 채우지 않으면 테이프가 빈다.
- 막힘이 다 뚫리지 않았으면 고무공을 눌러도 잉크가 올라오지 않는다. 더 쑤신 뒤 다시 누른다.
- 잉크가 바닥이면 마중물이 차지 않는다. 먼저 잉크를 채운다.
- 펜 팔을 든 채로 두면 테이프가 빈다.

# 차례

이 교범은 쪽 번호로 계통을 나눈다. 00~19쪽은 배 전체에 관한 일반 쪽이고, 20쪽부터는 계통마다 수리 절차를 싣는다. 교범을 펴면 위쪽의 계통 탭으로 그 계통의 쪽만 골라 볼 수 있다. 지시서와 조작 안내는 어느 탭에서나 보인다.

이상이 생기면 먼저 계통 상황판(02쪽)을 보고, 진단 표(03~05쪽)에서 원인을 하나로 좁힌 뒤 그 절차 쪽을 편다.

## 계통 탭

| 탭 | 쪽 |
| --- | --- |
| 일반 | 00~19 |
| 동력 | 20~22 |
| 배전반 | 23~25 |
| 공기 | 26~28 |
| 물 | 29~32 |
| 선체 | 33~37 |
| 감각 | 38~41 |
| 항법 | 42~43 |
| 케이블 | 44~45 |

- '전체' 탭에는 모든 쪽이 든다.
- 비어 있는 번호는 이 판에 싣지 않은 쪽이다.

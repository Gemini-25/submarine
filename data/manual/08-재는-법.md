# 재는 법

이 장에서는 계기와 손으로 상태를 재는 법을 설명한다. 수치는 계기로만 읽을 수 있다.

## 전압계

전압계를 들고 두 탐침을 대고 있는 동안 바늘이 값을 가리킨다. 대는 곳과 읽는 법은 '진단 표: 전기와 동력'의 '전압계 쓰는 법'에 있다.

(작성 중: 스위치 접점 강하는 WP8, 축전지 셀의 30V 눈금은 WP11)

## 손으로 만져 보기

손바닥으로 느끼는 정도와 온도의 관계는 다음과 같다.

| 느낌 | 온도 |
| --- | --- |
| 차갑다 | {{n:tuning.crew.touch.bandsC.0}}°C 미만 |
| 미지근하다 | {{n:tuning.crew.touch.bandsC.0}}~{{n:tuning.crew.touch.bandsC.1}}°C |
| 따뜻하다 | {{n:tuning.crew.touch.bandsC.1}}~{{n:tuning.crew.touch.bandsC.2}}°C |
| 뜨겁다 | {{n:tuning.crew.touch.bandsC.2}}~{{n:tuning.crew.touch.bandsC.3}}°C |
| 손을 댈 수 없다 | {{n:tuning.crew.touch.bandsC.3}}°C 이상. {{n:tuning.crew.touch.burnAtC}}°C 이상이면 화상을 입는다 |

- '축축하다'는 물기나 이슬이 맺혀 있다는 뜻이다. 전기가 통하는 곳이면 위험하다.
- '떨린다'는 회전부가 진동하고 있다는 뜻이다. 베어링이나 축의 이상을 의심한다.
- 배 안의 쇠붙이는 평소에 차갑다.

## 청진기

청진기의 끝을 기계 몸체에 대고 있는 동안 그 기계 안의 소리가 크게 들리고 방 안의 소리는 작아진다. 기계가 돌 때만 들을 수 있다. 펌프 몸체에서 들리는 소리와 그 뜻은 다음과 같다.

| 들리는 소리 | 뜻 |
| --- | --- |
| 고르게 웅웅거린다 | 베어링이 성하다 |
| 거칠게 긁힌다 | 베어링이 닳았다. 기름칠해도 긁히는 소리는 남는다 |
| 아무 소리가 없다 | 펌프가 서 있다 |

# 재는 법

이 장은 계기와 손으로 상태를 재는 법을 적는다. 수치는 계기로만 읽을 수 있다.

## 전압계

전압계를 들고 두 탐침을 대고 있는 동안 바늘이 값을 가리킨다. 대는 곳과 읽는 법은 '진단 표: 전기와 동력'의 '전압계 쓰는 법'에 있다.

축전지 셀 하나는 30V 눈금으로 잰다. 갑판 판을 열고 셀의 두 단자 너트에 탐침을 댄다.

| 대는 곳 | 읽은 값 | 뜻 |
| --- | --- | --- |
| 성한 셀 | 약 20V | 정상 |
| 열화한 셀 | 약 13V | 셀 열화. 혼자 뜨겁다 |
| 아주 죽은 셀 | 0에 가깝다 | 점퍼로 건너뛰어야 한다 |
| 빈 자리 | 0 | 셀이 빠져 있다 |

(작성 중: 스위치 접점 강하는 WP8)

## 손으로 만져 보기

손바닥으로 느끼는 정도와 온도의 관계는 다음과 같다.

| 느낌 | 온도 |
| --- | --- |
| 차갑다 | {{n:tuning.crew.touch.bandsC.0}}°C 아래 |
| 미지근하다 | {{n:tuning.crew.touch.bandsC.0}}~{{n:tuning.crew.touch.bandsC.1}}°C |
| 따뜻하다 | {{n:tuning.crew.touch.bandsC.1}}~{{n:tuning.crew.touch.bandsC.2}}°C |
| 뜨겁다 | {{n:tuning.crew.touch.bandsC.2}}~{{n:tuning.crew.touch.bandsC.3}}°C |
| 손을 댈 수 없다 | {{n:tuning.crew.touch.bandsC.3}}°C 넘음. {{n:tuning.crew.touch.burnAtC}}°C를 넘으면 화상을 입는다 |

- '축축하다'는 물기나 이슬이 맺혀 있다는 뜻이다. 전기가 통하는 곳이면 위험하다.
- '떨린다'는 돌아가는 부분이 떨고 있다는 뜻이다. 베어링이나 축을 의심한다.
- 배 안의 쇠붙이는 평소에 차갑다.

## 비중계

비중계는 축전지 셀의 충전 정도를 잰다. 갑판 판을 열고 셀의 통기 마개에 비중계 고무 관을 꽂아 전해액을 빨아올린다. 관 속의 뜨개가 떠오른 눈금을 읽는다. 갑판 판이 덮여 있으면 꽂을 수 없다.

| 비중 | 충전 |
| --- | --- |
| {{n:measure.hydrometer.sgFull}} | 가득 |
| 1.235 | 4분의 3 |
| 1.19 | 절반 |
| 1.145 | 4분의 1 |
| {{n:measure.hydrometer.sgEmpty}} | 바닥 |

- 셀이 모두 고르게 낮으면 축전지가 방전된 것이다.
- 한 셀만 다른 셀보다 빨리 떨어지면 그 셀이 열화한 것이다. 열화한 셀은 용량이 작아 같은 부하에도 세 배쯤 빨리 떨어진다.
- 새 예비 셀은 9할쯤 충전된 채 보관되어 있다.

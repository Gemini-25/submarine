# 재는 법

이 장에서는 계기와 손으로 상태를 재는 법을 설명한다. 수치는 계기로만 읽을 수 있다.

## 전압계

전압계를 들고 두 탐침을 대고 있는 동안 바늘이 값을 가리킨다. 대는 곳과 읽는 법은 '진단 표: 전기와 동력'의 '전압계 쓰는 법'에 있다.

- 철사를 감은 퓨즈는 끊기지 않으므로 퓨즈 소켓에서 늘 0으로 읽힌다. 배선이 타서 죽은 회로도 퓨즈 소켓은 0이고 부하 단자도 0이다.
- 칼날 스위치 양단: 스위치를 올린 채 칼날 위아래에 탐침을 댄다. 성한 접점은 2V 아래로 읽힌다. 그보다 크면 접점이 상했다('칼날 스위치 접점' 장). 스위치를 내린 채 대면 버스 전압이 읽힌다.

전압계에는 셀 하나를 재는 0~30V 눈금이 따로 있다. 갑판 판을 열고 셀의 두 단자 너트에 탐침을 대고 이 눈금을 읽는다.

| 대는 곳 | 읽은 값 | 뜻 |
| --- | --- | --- |
| 성한 셀 | 약 20V | 정상 |
| 열화한 셀 | 약 13V | 셀 열화. 다른 셀보다 온도가 높다 |
| 완전히 죽은 셀 | 0에 가깝다 | 점퍼로 건너뛰어야 한다 |
| 빈 자리 | 0 | 셀이 빠져 있다 |

## 손으로 만져 보기

손바닥으로 느끼는 정도와 온도의 관계는 다음과 같다.

| 느낌 | 온도 |
| --- | --- |
| 차갑다 | {{n:tuning.crew.touch.bandsC.0}}°C 미만 |
| 미지근하다 | {{n:tuning.crew.touch.bandsC.0}}~{{n:tuning.crew.touch.bandsC.1}}°C |
| 따뜻하다 | {{n:tuning.crew.touch.bandsC.1}}~{{n:tuning.crew.touch.bandsC.2}}°C |
| 뜨겁다 | {{n:tuning.crew.touch.bandsC.2}}~{{n:tuning.crew.touch.bandsC.3}}°C |
| 손을 댈 수 없다 | {{n:tuning.crew.touch.bandsC.3}}°C 이상. {{n:tuning.crew.touch.burnAtC}}°C 이상이면 화상을 입는다 |

- '축축하다'는 물기나 이슬이 맺혀 있다는 뜻이다. 전기가 통하는 곳이면 위험하다.
- '떨린다'는 손에 진동이 느껴진다는 뜻이다. 송풍 팬 전동기와 축 고리는 돌기만 해도 떨린다. 배수 펌프 몸체와 자이로 함은 베어링이 닳았을 때만 떨린다. 떨림과 함께 청진기 소리가 거칠면 베어링이나 축을 의심한다.
- 배 안의 쇠붙이는 평소에 차갑다.

## 비중계

비중계는 축전지 셀의 충전 정도를 잰다. 갑판 판을 열고 셀의 통기 마개에 비중계 고무 관을 꽂아 전해액을 빨아올린다. 관 속의 뜨개가 떠오른 눈금을 읽는다. 갑판 판이 덮여 있으면 꽂을 수 없다.

| 비중 | 충전 |
| --- | --- |
| {{n:measure.hydrometer.sgFull|2}} | 가득 |
| 1.235 | 4분의 3 |
| 1.19 | 절반 |
| 1.145 | 4분의 1 |
| {{n:measure.hydrometer.sgEmpty|2}} | 바닥 |

- 셀이 모두 고르게 낮으면 축전지가 방전된 것이다.
- 한 셀만 다른 셀보다 빨리 떨어지면 그 셀이 열화한 것이다. 열화한 셀은 용량이 작아 같은 부하에도 세 배쯤 빨리 떨어진다.
- 새 예비 셀은 9할쯤 충전된 채 보관되어 있다.

## 청진기

청진기의 끝을 기계 몸체에 대고 있는 동안 그 기계 안의 소리가 크게 들리고 방 안의 소리는 작아진다. 기계가 돌 때만 들을 수 있다. 펌프 몸체에서 들리는 소리와 그 뜻은 다음과 같다.

| 들리는 소리 | 뜻 |
| --- | --- |
| 고르게 웅웅거린다 | 베어링이 성하다 |
| 거칠게 긁힌다 | 베어링이 닳았다. 기름칠해도 긁히는 소리는 남는다 |
| 아무 소리가 없다 | 펌프가 서 있다 |

## 저항 브리지

저항 브리지는 통신 책상에 놓여 있다. 선택 손잡이를 누를 때마다 잴 분기함이 C1부터 C8까지 차례로 바뀌고, 그다음은 끊음이다. 검류계 바늘이 고른 분기함의 절연 저항을 가리킨다. 눈금은 왼쪽 끝이 0.01MΩ, 오른쪽 끝이 100MΩ이다. 끊음이면 바늘이 오른쪽 끝에 쉰다.

분기함 여덟 곳의 절연을 잴 수 있다. **그 회로 스위치를 내려야 읽힌다.** 스위치가 올라가 있으면 바늘이 떨기만 하고 서지 않는다. 이때는 읽지 말 것.

| 읽은 값 | 분기함 |
| --- | --- |
| {{n:measure.bridge.insulationMOhm.2.1}}MΩ 넘음 | 말라 있다 |
| {{n:measure.bridge.insulationMOhm.4.1}}~{{n:measure.bridge.insulationMOhm.2.1}}MΩ | 축축하다. 아직 새지는 않는다 |
| {{n:measure.bridge.insulationMOhm.4.1}}MΩ 아래 | 젖었다. 누전한다 |

- 피복을 벗긴 채 테이프를 감지 않은 이음도 젖은 분기함처럼 낮게 읽힌다.

## 배전반 전류계

배전반 아래쪽에 회로마다 전류계가 하나씩 있다. 그 회로로 지금 흐르는 전류를 가리킨다. 평소 값은 그 회로에서 돌고 있는 장비의 전류를 더한 것이다.

| 회로 | 평소 켜 두는 장비 | 장비 전류 |
| --- | --- | --- |
| C1 | 실내 조명 | {{a:devices.cabin_lights.powerW|2}}A |
| C2 | 송풍 팬, 산소 화로 점화기 | {{a:devices.vent_fan.powerW|2}}A + {{a:devices.o2_igniter.powerW|2}}A |
| C3 | 전동 배수 펌프 | {{a:devices.bilge_pump.powerW|2}}A |
| C4 | 상황판, 청음기 | {{a:devices.status_panel.powerW|2}}A + {{a:devices.hydrophone.powerW|2}}A |
| C5 | 자이로컴퍼스, 항법 계산기 | {{a:devices.gyrocompass.powerW|2}}A + {{a:devices.nav_computer.powerW|2}}A |
| C6 | 사이펀 기록기 | {{a:devices.siphon_recorder.powerW|2}}A |
| C7 | 납땜인두 (켰을 때) | {{a:devices.soldering_iron.powerW|2}}A |
| C8 | 추진 전동기 (전속) | {{a:devices.propulsion.powerW|2}}A |

- 전류계가 장비 전류를 더한 것보다 많이 가리키면 그 회로 어딘가로 전기가 샌다. 분기함을 본다.
- 전류계가 0이면 회로가 죽었거나 돌고 있는 장비가 없다.
